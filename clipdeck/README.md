# ClipDeck

Менеджер буфера обмена и конструктор скриптов клавиатуры для Windows 10/11. Окно открывается поверх любых программ и игр по горячей клавише и не забирает у них фокус.

## Как получить exe
1. **Локально:** установите .NET SDK 8 и запустите `build.bat`. Результат: `publish\ClipDeck.exe`.
2. **Через GitHub без установки .NET:** загрузите папку в свой репозиторий, откройте «Actions» → «Build ClipDeck» → «Run workflow» и скачайте артефакт `ClipDeck-standalone` (работает везде, ~70 МБ) или `ClipDeck-small` (маленький, нужен .NET 8 Desktop Runtime).

## Как пользоваться
- **Ctrl+Alt+V**: показать или скрыть окно (меняется в «Настройках»). Программа живёт в трее.
- **Буфер:** всё, что вы копируете, попадает в список. Клик по записи вставляет её в то окно, где вы работали (Ctrl+V). Можно включить «Enter после вставки» (сразу отправить) и «Печатать, а не вставлять». Звёздочка закрепляет запись, поиск фильтрует.
- **Скрипты:** цепочка шагов «Клавиша», «Текст», «Пауза». Каждому скрипту можно дать горячую клавишу (нажмите в поле) и число повторов (0 = пока не остановите). Повторный запуск горячей клавиши или **Ctrl+Alt+End** останавливает скрипт.
  Пример: `Клавиша T` → `Пауза 150` → `Текст gg wp` → `Клавиша Enter`.
- Клик по полю ввода временно даёт окну фокус клавиатуры, для остальных кликов фокус остаётся у вашей программы.

## Ограничения
- Поверх игр окно работает в режиме «в окне без рамки». В настоящем эксклюзивном полноэкранном режиме Windows может его скрыть.
- Чтобы вводить в окна, запущенные от администратора, запустите ClipDeck от администратора.
- Если игра не реагирует на нажатия, включите «Режим сканкодов» и увеличьте «Длительность нажатия».
- Автонажатие клавиш в онлайн-играх с античитом (Vanguard, EasyAntiCheat и др.) может привести к блокировке аккаунта.
- Данные хранятся в `%AppData%\ClipDeck`. По умолчанию на диск сохраняются только закреплённые записи. Записи из менеджеров паролей в историю не попадают.
